## C. 训练记录 —— 产品最高频模块

| # | 功能 | 状态 | 说明 / 验收要点 |
|---|---|---|---|
| C1 | 中文动作库 | 🔨 | 分类（胸/背/腿/肩/手臂/核心）+ 搜索（中文 + 拼音首字母）+ 器械标注 |
| C2 | 自定义动作 | 🔨 | 新增动作可指定肌群、器械 |
| C3 | 开始训练 | 🔨 | 从今日计划 / 自由训练两种入口 |
| C4 | **记组界面** | 🔨 | **方案缺失，必须补规范**（评审 P0-5）：重量 ±2.5kg 步进、次数 ±1、沿用上一组 |
| C5 | 组间计时 | 🔨 | 默认 90s，可调；**离开 App 回来仍准确**（按时间戳算，不靠 setInterval 累加） |
| C6 | 上一组数据可见 | 🔨 | 训练中始终显示「上次 62.5kg × 8」，避免记错 |
| C7 | 切换动作 / 同类替代 | 🔨 | 器械被占用场景 → 推荐同肌群替代动作（对应原始痛点 1） |
| C8 | 添加动作（训练中） | 🔨 | 不打断当前动作的记录状态 |
| C9 | 训练总结页 | 🔨 | 总容量主数字 + 组数 / 时长 / PR + 动作明细 |
| C10 | PR 自动识别 | ⚠️ | **需先定义口径**（评审 P1-11）：最大重量 / 估算 1RM / 最大单组容量 |
| C11 | 训练容量统计 | ⚠️ | **需先定义口径**：重量×次数 是否计入热身组、是否计入自重动作 |
| C12 | 训练日历 | 🔨 | 有练打点，可点进看当日明细 |
| C13 | 左滑编辑 / 删除记录 | ⚠️ | 与切页手势冲突，需限定为「列表项内左滑」（评审 P0-4） |
| C14 | 记录导出 CSV / Excel | 🔨 | 纯本地生成，不调网络 |

## D. 饮食

| # | 功能 | 状态 | 说明 / 验收要点 |
|---|---|---|---|
| D1 | 离线拍照识餐 | ✅ | Food-101 MobileNetV2，实测加载 ~0.5s / 推理 ~60ms，无需联网与密钥 |

| D3b | 食物库数据源接入 | ✅ | 源：[Sanotsu/china-food-composition-data](https://github.com/Sanotsu/china-food-composition-data)（CSV 341KB / 1,677 条 / 含能量·蛋白·脂肪·碳水·膳食纤维·钠）；转换脚本已验证可跑通（映射 61 个原始类别 → 13 个 App 分类），输出 JSON 约 263KB，建议**作为独立文件按需加载**而非内嵌 HTML；许可需登记进 THIRD-PARTY-NOTICES |
| D4 | 三餐时间窗记账 | ✅ | 过点未记显示「没吃」 |
| D5 | 营养素统计 | ✅ | 热量 / 蛋白 / 碳水 / 脂肪 |
| D6 | 照片本地处理提示 | 🔨 | 「照片已在本地处理，未保留原图」（隐私可视化） |

4. 训练记组：**3 次点击内记完一组**
5. 无假入口：界面上出现的入口，功能必须已经能用
