本版设计稿的取舍说明（与 brief v2 一一对应）

  • 记组是主干，不是视频识别。训练中页把「重量 / 次数步进器 + 完成本组」放在拇指最舒服的位置，3 次点击能记完一组；视频识别留到 v1.1 做复盘与免手记，不占主干。
  • 没有「识别重量」。按 brief v2 的修正，重量走「记忆上次 + 一键步进（±2.5kg）」，页面里显示的是「上次 62.5kg × 8」而不是 AI 识别结果。
  • 器械被占用有解。训练中页给「切换动作」入口，动作库页提示长按看「同类替代」——正面对上原始痛点 1。
  • 计划只给建议、不自动改。计划页用「建议 + 采纳/忽略」，并说明原因与代价（约 +8 分钟），避免用户第二天发现计划变了却不知为何。
  • 玻璃很克制。整屏只有吸顶栏与底部 Tab 栏两处磨砂；内容全是实心表面 + 发丝线——这是上次 UI 被说「廉价 AI 感」的根因，这次从源头避开。
  • 重复的界面元素只有一个强调色。绿色只用于：主按钮、已完成勾、选中态、数据强调。分类信息（肌群占比）用同色不同透明度，不再上第二种色。
  • 「为你推荐」是按剩余热量 + 时间段动态算的（05 画板）：按早/午/晚/加餐各自的常见食物池，结合该餐「已记 / 该餐预算」筛选，显示「午餐 · 已记 620 / 780 kcal」；该餐超量时自动切换为低卡轻食。这条并非静态占位文案。
  • 食物库改用权威数据源。《中国食物成分表标准版 第 6 版》结构化数据（Sanotsu/china-food-composition-data）：1,677 条、含能量 / 蛋白 / 脂肪 / 碳水 / 膳食纤维及全套矿物质，单文件仅 341 KB，随包内置后仍完全离线。现有内置库 231 条 → 扩充约 7 倍，且以中餐为主。
  • 色值按 WCAG 实算修正过。原方案二级文本 3.62:1、三级 1.68:1、强调色文字 2.22:1，都低于其自订的 4.5:1；现为浅色强调 #1E7A34=5.4:1、二级文本 5.2:1。另外修掉一处实现 bug：底部渐隐遮罩原本盖住了固定主按钮（把 #1E7A34 冲成 #97BEA3），已改为独立底栏，按钮不再受影响。
